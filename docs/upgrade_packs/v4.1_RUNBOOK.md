# 🧭 v4.1 RUNBOOK (운영 메뉴얼)
목표: “대화”가 아니라 “문서/리포트/게이트”가 프로젝트를 끌고 가도록, 팀이 동일한 절차로 움직이게 한다.

------------------------------------------------------------
0) 핵심 원칙 (절대 규칙)
------------------------------------------------------------
1. Plan Mode Gate: Phase 0에서 승인(Approval) 전엔 구현(Phase 1+) 금지
2. Policy/Design/Security Gate: PR은 게이트 PASS 전엔 merge 금지
3. Evidence First: 모든 PASS/FAIL은 리포트/증거팩으로 남겨야 한다
4. Decision Ledger: 모든 중요한 이벤트(승인/변경/예외/릴리즈/장애수정)는 결정 로그에 기록되어야 한다
5. Exceptions: CRITICAL 예외는 금지, MAJOR 예외는 만료일 필수 + 결정 로그 필수

------------------------------------------------------------
1) 새 기능 시작 (/new ...)
------------------------------------------------------------
[사용자 입력 예시]
- "/new todo 리스트 만들어줘"

[절차]
A. spec_analyst: Gap-driven Q&A (최소 질문) → 문서 고정
   - 산출: MASTER_PLAN.md / PLAN_OUTPUT.md / DESIGN_SYSTEM.md / POLICY_RULES.md / SECURITY_POLICY_RULES.md
   - state.json의 approval_status=APPROVED로 업데이트

B. orchestrator: Phase 0 Gate 확인
   - approval_status=APPROVED 확인
   - PLAN_OUTPUT 존재 확인

C. universal_dev: Phase 1~2 수행
   - 스캐폴딩/기능 구현
   - PR 생성

D. CI: policy-gates.yml 자동 실행
   - 디자인/보안 정책 검사
   - Evidence 업로드
   - Decision Ledger 자동 기록(implicit)

[완료 조건]
- 모든 required checks PASS
- Evidence artifacts 업로드됨
- DECISION_LOG.md에 이벤트가 append됨

------------------------------------------------------------
2) 기능 변경 (/change ...)
------------------------------------------------------------
[사용자 입력 예시]
- "/change todo에 due date 추가해줘"

[절차]
A. CHANGE_REQUEST.md 작성 (필수)
B. 승인(Approval) 후 “EXPLICIT Decision” 기록 (자동화 스크립트 실행)
C. Dev 구현 → CI Gate → Evidence 업데이트

------------------------------------------------------------
3) 버그/장애 (/fix ...)
------------------------------------------------------------
[사용자 입력 예시]
- "/fix 저장이 가끔 실패해"

[절차]
A. INCIDENT.md 작성 (재현/영향/증거)
B. systematic debugging (원인 분류) → 최소 수정 PR
C. CI Gate → PASS 시 병합
D. “IMPLICIT Decision” 기록(자동화)

------------------------------------------------------------
4) 예외 처리 (Exception Workflow)
------------------------------------------------------------
[언제]
- MAJOR 정책 위반이 있으나 임시로 통과가 필요한 경우
- CRITICAL은 절대 불가

[절차]
A. EXCEPTIONS.md에 Entry 추가 (만료일 필수)
B. 승인자(Owner) 승인
C. EXPLICIT Decision 기록 (자동화 스크립트 실행)
D. CI는 예외를 확인하여 WARN으로 통과 가능(구현 시)
E. 만료일 경과 시 CI에서 자동 FAIL (만료 감시 스크립트)

------------------------------------------------------------
5) 팀 공통 명령(로컬)
------------------------------------------------------------
- Change 승인 로그 기록:
  python3 tools/ledger/log_explicit_from_change.py --root . --change CHANGE_REQUEST.md --actor lead

- Incident fix 로그 기록:
  python3 tools/ledger/log_implicit_from_incident.py --root . --incident INCIDENT.md --actor ci

- Exception 만료 검사:
  python3 tools/policy/check_exceptions_expiry.py --root . --exceptions EXCEPTIONS.md

------------------------------------------------------------
6) 자주 터지는 실패 케이스 대응
------------------------------------------------------------
- policy FAIL:
  1) report에서 위반 Top3 확인
  2) autofix 가능하면 autofix 적용
  3) 재검사 후 PASS
- security FAIL:
  1) dependency vuln이면 업그레이드 우선
  2) secret이면 즉시 제거 + 키 회전
- drift CRITICAL:
  1) DESIGN_TOKENS / DESIGN_SYSTEM 변경 이유 확인
  2) Decision Ledger에 변경 근거 기록 후 진행

import os
import sys
import json
import datetime
import subprocess
from typing import Dict, Any, Optional

# ---------------------------------------------------------
# Create EXPLICIT Decision Event from CHANGE_REQUEST.md
# - Validates approval status in CHANGE_REQUEST.md
# - Writes a decision event via tools/ledger/log_decision.py
#
# Usage:
#   python3 tools/ledger/log_explicit_from_change.py --root . --change CHANGE_REQUEST.md --actor lead
# ---------------------------------------------------------

def read_text(path: str) -> str:
    with open(path, "r", encoding="utf-8") as f:
        return f.read()

def parse_simple_field(md: str, key: str) -> Optional[str]:
    # naive parse: lines like "- Decision: APPROVED"
    for line in md.splitlines():
        s = line.strip()
        if s.lower().startswith("- " + key.lower() + ":"):
            return s.split(":", 1)[1].strip()
    return None

def ensure_state(root: str) -> None:
    p = os.path.join(root, ".orchestrator", "state.json")
    os.makedirs(os.path.dirname(p), exist_ok=True)
    if not os.path.exists(p):
        with open(p, "w", encoding="utf-8") as f:
            json.dump({"mode": "PLAN", "approval_status": "APPROVED", "current_phase": "CHANGE"}, f, ensure_ascii=False, indent=2)

def update_state(root: str, patch: Dict[str, Any]) -> None:
    p = os.path.join(root, ".orchestrator", "state.json")
    state: Dict[str, Any] = {}
    if os.path.exists(p):
        with open(p, "r", encoding="utf-8") as f:
            try:
                state = json.load(f)
            except Exception:
                state = {}
    state.update(patch)
    os.makedirs(os.path.dirname(p), exist_ok=True)
    with open(p, "w", encoding="utf-8") as f:
        json.dump(state, f, ensure_ascii=False, indent=2)

def main():
    root = "."
    change_path = "CHANGE_REQUEST.md"
    actor = "lead"

    args = sys.argv[1:]
    if "--root" in args:
        root = args[args.index("--root") + 1]
    if "--change" in args:
        change_path = args[args.index("--change") + 1]
    if "--actor" in args:
        actor = args[args.index("--actor") + 1]

    change_abs = os.path.join(root, change_path)
    if not os.path.exists(change_abs):
        print(f"ERROR: change request not found: {change_abs}")
        sys.exit(2)

    md = read_text(change_abs)
    decision = parse_simple_field(md, "Decision")
    approved_by = parse_simple_field(md, "Approved By") or ""
    title = parse_simple_field(md, "Title") or "Change Request"

    if (decision or "").upper() != "APPROVED":
        print("ERROR: CHANGE_REQUEST.md is not approved. Set '- Decision: APPROVED' first.")
        sys.exit(1)

    ensure_state(root)
    update_state(root, {
        "mode": "CHANGE",
        "approval_status": "APPROVED",
        "current_phase": "CHANGE_REQUEST",
        "change_title": title,
        "approved_by": approved_by,
        "updated_at": datetime.datetime.now().astimezone().isoformat(timespec="seconds"),
    })

    cmd = ["python3", "tools/ledger/log_decision.py", "--root", root, "--actor", actor, "--type", "EXPLICIT"]
    print("RUN:", " ".join(cmd))
    r = subprocess.run(cmd)
    sys.exit(r.returncode)

if __name__ == "__main__":
    main()

import os
import sys
import re
import datetime
from typing import List, Tuple, Optional

# ---------------------------------------------------------
# Exception Expiry Checker (v4.1)
# - Reads EXCEPTIONS.md
# - Fails CI if any ACTIVE exception is expired
#
# Supported date format: YYYY-MM-DD
#
# Usage:
#   python3 tools/policy/check_exceptions_expiry.py --root . --exceptions EXCEPTIONS.md
# ---------------------------------------------------------

DATE_RE = re.compile(r"\b(\d{4}-\d{2}-\d{2})\b")

def read_text(path: str) -> str:
    with open(path, "r", encoding="utf-8") as f:
        return f.read()

def parse_exception_blocks(md: str) -> List[str]:
    # Split by "## Exception Entry" or "### 1. Exception Overview"
    # Keep it simple: split by "---" separators if present
    if "\n---\n" in md:
        parts = md.split("\n---\n")
        return [p.strip() for p in parts if "Exception ID" in p]
    # fallback: entire doc as one block
    return [md]

def find_field(block: str, field: str) -> Optional[str]:
    # matches lines like "- Status: ACTIVE"
    for line in block.splitlines():
        s = line.strip()
        if s.lower().startswith("- " + field.lower() + ":"):
            return s.split(":", 1)[1].strip()
    return None

def parse_date(s: str) -> Optional[datetime.date]:
    try:
        return datetime.datetime.strptime(s, "%Y-%m-%d").date()
    except Exception:
        return None

def main():
    root = "."
    exceptions_path = "EXCEPTIONS.md"

    args = sys.argv[1:]
    if "--root" in args:
        root = args[args.index("--root") + 1]
    if "--exceptions" in args:
        exceptions_path = args[args.index("--exceptions") + 1]

    p = os.path.join(root, exceptions_path)
    if not os.path.exists(p):
        # If no exceptions file, treat as PASS
        print("OK: no EXCEPTIONS.md found")
        sys.exit(0)

    md = read_text(p)
    blocks = parse_exception_blocks(md)

    today = datetime.datetime.now().date()
    expired: List[Tuple[str, str]] = []

    for b in blocks:
        ex_id = find_field(b, "Exception ID") or "UNKNOWN"
        status = (find_field(b, "Status") or "ACTIVE").upper()
        exp_str = find_field(b, "Expiration Date") or ""

        # Only check ACTIVE exceptions
        if status != "ACTIVE":
            continue

        # Must have expiration date
        if not exp_str:
            expired.append((ex_id, "MISSING_EXPIRATION_DATE"))
            continue

        exp_date = parse_date(exp_str)
        if exp_date is None:
            expired.append((ex_id, f"INVALID_DATE_FORMAT:{exp_str}"))
            continue

        if exp_date < today:
            expired.append((ex_id, f"EXPIRED:{exp_str}"))

    if expired:
        print("FAIL: expired/invalid ACTIVE exceptions detected")
        for ex_id, reason in expired:
            print(f"- {ex_id}: {reason}")
        sys.exit(1)

    print("PASS: no expired ACTIVE exceptions")
    sys.exit(0)

if __name__ == "__main__":
    main()
